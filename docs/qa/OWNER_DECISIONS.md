# Zilbio v3.0.4 — Owner Decisions Register
### Tracked Design Ambiguities and Owner Resolutions per Addendum B.4

| ID | Feature / Component | Question | Option A | Option B | Default Applied | Status | Owner Resolution |
|---|---|---|---|---|---|---|---|
| **OD-01** | Call Signaling (Part 7.1) | How should the app handle an incoming call when the caller hangs up before the receiver answers (unanswered call duration < 5 seconds)? | Immediately dismiss the incoming call screen/overlay on the receiver device and log a "Canceled Call" event in call history. | Keep the ringing overlay active until a 30-second timeout, then record as a standard missed call. | Option A: Dismiss overlay immediately and log as canceled call. | **OPEN** | Awaiting recorded owner decision. |
| **OD-02** | Disappearing Messages (Part 9.4) | Should local cached media files (audio notes, image attachments) be immediately deleted from physical device flash storage when an ephemeral message expires? | Purge cached attachment files immediately from device storage upon message expiration. | Retain cached files in internal cache storage until the OS/app cache eviction manager cleans them up. | Option B: Retain until storage cache cleanup to avoid uncoordinated I/O stalls during UI rendering. | **OPEN** | Awaiting recorded owner decision. |
| **OD-03** | Gemini Quota Warning (Part 4.2) | How should the app handle reaching the Gemini daily quota limit (1,400 requests/day)? | Fail silently to on-device ML Kit translation without blocking messaging flow or displaying a warning banner. | Display a persistent or prominent quota warning banner in the chat header and disable real-time translation until reset. | Option A: Seamless fallback to on-device ML Kit translation with non-blocking log. | **OPEN** | Awaiting recorded owner decision. |
| **OD-04** | Gemini Model Substitution (Part 4 / Gate 4) | How should the translation engine proceed if `gemini-3.5-flash-lite` is unavailable on the live endpoint? | Enforce strict model binding to `gemini-3.5-flash-lite` without automated model substitution; fall back only to on-device ML Kit. | Enable automated fallback cascade to available models (e.g. `gemini-1.5-flash`, `gemini-2.5-flash`). | Option A: Strict single model binding with model fallback cascade disabled (`ENABLE_MODEL_FALLBACK = false`). | **OPEN** | Awaiting recorded owner decision. |
